JavaScript and JQuery

This flash card contains definitions for various programming language.

Variable
JavaScript
A named container used to store a value that can be updated later, declared with let, const, or var.
Function
JavaScript
A reusable block of code defined once and run whenever it's called, optionally taking inputs and returning a value.
Array
JavaScript
An ordered list-like object used to store multiple values in a single variable, accessed by index.
Object
JavaScript
A collection of related data stored as key-value pairs, used to model real-world things and structures.
Event Listener
JavaScript
A function attached to an element that runs automatically when a specific event, like a click, happens.
Selector
jQuery
The $() syntax used to find and select one or more elements on the page so they can be read or changed.
